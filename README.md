# Воркшоп по git - удаление секретного ключа из истории коммитов

Контекст - проект, выбранный для данного кейса является клоном Яндекс Погоды, и использует внешнее погодное API для получения информации о погоде. Для использования данного апи необходим индивидуальный ключ.

Суть задачи:
- В файле `src/main/resources/app.properties` на строке 26 закоммичен ключ к API в открытом виде
- Ключ появился там в не в последнем коммите, а примерно на середине истории коммитов
- Необходимо заменить ключ на плейсхолдер `${API_KEY}`. Так, чтобы ни в одном коммите в истории ключа в открытом виде не существовало

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
- Сравните локальную и удалённую ветку main, единственная разница должна быть в замене API ключа на плейсхолдер
